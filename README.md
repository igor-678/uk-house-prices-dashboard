# UK House Prices Dashboard

A data analytics project built with Python, SQLite and Streamlit.

## Project Overview

This project analyses UK residential property prices using historical House Price Index (HPI) data.

The dashboard will allow users to:

- Explore house price trends over time
- Compare UK regions
- Analyse property types
- View sales volume statistics
- Visualise housing market changes from 1995 onwards

## Tech Stack

- Python
- Pandas
- SQLite
- Streamlit
- Plotly
